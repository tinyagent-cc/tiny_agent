# Pip brain v1, Plan C1: LinkBody, say/hud/scene, listen/look judgment, director, fallback HUD

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The brain talks to the body over the UART wire, narrates what it does on the HUD and in speech bubbles, listens through the cortex, looks through the camera, speaks through the voice service, and can run scripted demo scenes including an unattended tour.

**Architecture:** `IBody` grows `say/hud/scene/speak`. A new `LinkBody` owns the serial port: a reader thread decodes frames (events and senses come up, commands and PCM audio go down). `Cortex` and `Voice` are tiny httplib clients. `Judgment` gets a transcript, a `say` tool (bubble + TTS streamed on a `Speaker` thread with a bounded queue) and a `look` tool. `Brain::process_event` runs the listen → think → answer flow on `button.hold` and pushes `reflex_us`, `judge_ms`, `mind` to the HUD. `Director` runs named scenes on its own thread, one at a time, with an injectable clock.

**Tech Stack:** C++20, cpp-httplib, nlohmann/json, tiny_agent (`make_agent`, `DynamicTool`, `model_fallback`, reflex middleware), POSIX termios for the UART, doctest. Builds on the Mac (`build-brain`) and on the Pi 5 (`brain/scripts/build-pi5.sh`), deploys to the Zero.

**Spec:** `docs/superpowers/specs/2026-08-23-pip-wow-demo-design.md` (in `~/git/tiny_agent_cpp`), sections "Brain v1", "Services" (the HTTP shapes), "Error handling", "Testing".

**Repo:** `~/git/pip`, directory `brain/` only (Plan A is changing `core/` and `firmware/` in parallel in another worktree; do not touch them). Current main: `d9d6af2`.

## Global Constraints

- Only `brain/` and `PROTOCOL.md`'s "Brain endpoints" section change in this plan.
- Link frame (identical contract to the firmware plan): `0xA5 | type u8 | len u16 LE | payload | crc8(type,len_lo,len_hi,payload)`; type `0x01` JSON, `0x02` AUDIO (s16le mono 16 kHz, ≤ 512 bytes payload); CRC-8 poly 0x07 init 0 (crc of "123456789" = 0xF4). Implement it in `brain/src/wire.hpp` (header-only, ~60 lines); a later cleanup may unify it with `core/`.
- Up-frames from the body (JSON): `{"event":"button.press"}` etc., `{"senses":{"light_lux":..,"temp_c":..,"button":"up"}}`, `{"hello":{"fw":"v1","protocol":1}}`, `{"pong":true}`. Down-frames: `{"cmd":"express","emotion":..}`, `{"cmd":"chirp","name":..}`, `{"cmd":"led","r":..,"g":..,"b":..}`, `{"cmd":"say","text":..}` (≤ 95 chars), `{"cmd":"hud", ...subset of reflex_us,judge_ms,brain,cortex,mind,scene}`, `{"cmd":"scene","name":..}`, `{"cmd":"ping"}`.
- Emotions v1: `idle, happy, sleepy, thinking, alert, wink, surprised, sad, listening, talking`. Chirps: `rise, trill, drop, purr, boot, sad` (the body may 400 `boot`/`sad` until Plan B; tolerate a failed chirp).
- Cortex HTTP: `POST /listen {"seconds":4}` → `{"text":"...","ms":N}`; `POST /see {"question":"..."}` → `{"text":"...","ms":N}`; `GET /health` → `{"ok":true,...}`. Voice HTTP: `POST /tts {"text":"..."}` → body raw s16le mono 16 kHz PCM (`Content-Type: application/octet-stream`); `GET /health`.
- Timeouts: cortex listen = seconds + 10 s, see = 25 s, voice tts = 15 s, health 1 s. The worker never blocks on speech: `Speaker` thread + bounded queue (4 items, drop oldest with a log note).
- Every new public behaviour has a doctest; `ctest` green on the Mac before each commit; `-Wall -Wextra` clean (gcc 14 on the Pi: use explicit member construction, never partial designated init).
- Mac build: `cmake -S brain -B build-brain -G Ninja -DCMAKE_BUILD_TYPE=Debug -DCMAKE_TOOLCHAIN_FILE=$HOME/.vcpkg/scripts/buildsystems/vcpkg.cmake -DTINY_AGENT_DIR=$HOME/git/tiny_agent_cpp -DPIP_RETE_DIR=$HOME/git/rete_cpp && cmake --build build-brain && ctest --test-dir build-brain --output-on-failure`.

### Task 3: LinkBody

**Files:** `brain/src/link_body.hpp/.cpp`, `brain/tests/fake_link.hpp`, `brain/tests/test_link_body.cpp`.

**Interfaces:**
```cpp
class LinkBody : public IBody {
public:
    // Opens dev (termios raw, baud, 8N1, VMIN 0 VTIME 1) or adopts an already-open fd (tests). Starts the reader thread.
    explicit LinkBody(const std::string& dev, int baud = 921600);
    explicit LinkBody(int fd);                                      // for tests (pipe/pty); LinkBody owns and closes it
    ~LinkBody();
    void set_event_sink(std::function<void(const json&)> sink);    // called from the reader thread for every {"event":..} frame (the sink must be quick: Brain::post_event is)
    void set_fallback(IBody* http);                                 // used when !alive()
    // IBody: express/chirp/led/say/hud/scene -> JSON down-frames; senses() -> last cached from a {"senses":..} frame (ok if < 3 s old) else fallback; ping() sends {"cmd":"ping"}
    // speak(): 256-sample (512 B) AUDIO frames, paced: frame i may not be written before t0 + i*16 ms - 200 ms; returns false if !alive()
    bool alive() const override;                                    // any good frame in the last 2000 ms
    struct Stats { uint64_t rx_frames, rx_bad, tx_frames, tx_audio; }; Stats stats() const;
};
```
Writes are serialised with a mutex; audio frames interleave with command frames (a command during speech is written between audio frames, which is what "chirps pre-empt speech" needs on the body side).

Checks: `express("wink")` arrives as `{"cmd":"express","emotion":"wink"}`; an up `{"event":"button.press"}` reaches the sink; `{"senses":{...}}` then `senses()` returns it with `ok==true`; `alive()` false before any frame, true after; `speak` of 1600 samples produces 7 audio frames (6×256 + 64) and takes ≥ 80 ms (paced: 1600 samples = 100 ms minus 200 ms lead → at least the write time; assert frame count and that frames carry the right bytes, plus a 16000-sample speak takes ≥ 700 ms); garbage on the wire does not kill the reader.

### Task 7: Director and scenes

**Files:** `brain/src/director.hpp/.cpp`, `brain/tests/test_director.cpp`.

**Interfaces:**
```cpp
struct Clock { virtual ~Clock() = default; virtual void sleep_ms(int ms) = 0; virtual int64_t now_ms() = 0; };
class Director {
public:
    Director(Brain& brain, IBody& body, EventLog& log, Clock& clock);
    bool run(const std::string& name);     // false if unknown or one already running; runs on its own thread; returns immediately
    bool running() const; std::string current() const; void wait();
    static std::vector<std::string> names();   // {"reflex","night","fallback","fever","who","tour"}
};
```
Scenes (each step: `brain.set_scene_name(n)` first; `body.say` lines ≤ 90 chars; waits via clock):
- `reflex`: say "Press my button." wait 6 s (if no press arrives in 6 s, `brain.inject("button.press")`); caption `reflex` then say "That was a rule. Microseconds. Now hold me and ask something." wait 12 s (if no hold arrived, inject `button.hold`).
- `night`: say "Cover my light sensor." wait 8 s; if no `light.low` seen, `inject("light.low")`; say "Dark means sleepy, and my rules cap the LED." then `brain.inject("button.hold")` is NOT used; instead call `brain.speaker()->say("Rule capped the LED to forty.")` after `body.led(255,0,0)` which the reflex policy clamps when night (ask the brain: `brain.led_capped(255,0,0)` helper that goes through `policy.clamp`); wait 5 s; `inject("light.high")`.
- `fallback`: caption `fallback`; say "Cortex offline. The next answer comes from the Pi five."; the brain gets `brain.set_force_fallback(true)` (Judgment skips the primary: `react` uses llm2 directly when forced) for 60 s or until the next hold completes; say "Hold me and ask something."
- `fever`: say "Warm my chip."; wait 10 s; if no `temp.hot` happened, `brain.inject("temp.hot")`.
- `who`: say "Who's there?"; `brain.speaker()->say(brain.look("Describe who or what is in front of the camera in one short sentence."))` (brain exposes `std::string look(q)` → cortex.see or "I can't see right now").
- `tour`: say "I'm Pip. My body is a Pico: face, chirps, senses." (2 s) "My brain is a Pi Zero: rules in microseconds, an agent in seconds." (2 s) "My cortex is a Jetson: ears, eyes, and the model that thinks." (2 s) "If the cortex is gone, a Pi five answers instead, and it also lends me its voice." (2 s); then `reflex` (with injected events), `night` (injected), `who`; then `body.express("idle")`, caption cleared. Total ≈ 2 min.
- Every scene ends with `brain.set_scene_name("")` and `body.express("idle")` unless the scene set another mood.
